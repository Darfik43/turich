# Турич — лэндинг турнира

Статическая страница: один файл `index.html`, без сборки.

## Как править

Все данные лежат в начале блока `<script>` в `index.html`:

- `TOURNAMENT.date`: дата в шапке.
- `TEAMS`: названия команд и составы (`["Имя Фамилия", "ник"]`).
- `RESULTS`: результаты группы. Номер тура → массив победителей по матчам в том порядке, как они показаны на странице (`1` — левая команда, `2` — правая, `null` — не сыграно). Таблица и шахматка пересчитаются сами.

## Лого команд

Положи картинки в `logos/` с именами `team-1.png` … `team-7.png` (квадратные, от 256×256). Пока файла нет, на его месте показывается заглушка.

## Хостинг на GitHub Pages

1. Создай репозиторий (например, `turich`) и загрузи туда содержимое этой папки.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Сайт появится по адресу `https://<логин>.github.io/turich/`.
